## What I'm working on

- **Multi-tenant SaaS on GCP** — tenant-isolated Firestore data models, Firebase Auth with custom claims for RBAC, App Check + reCAPTCHA Enterprise, separate dev/prod Cloud Run environments.
- **CI/CD** — Bitbucket Pipelines building container images and deploying to Cloud Run, with environment-scoped secrets in Secret Manager.
- **Automation** — self-hosted n8n on Cloud Run wiring Google Workspace, Visma Sign and internal tooling together; Cloud Functions for event-driven glue.
- **AI-assisted tooling** — building agents and internal tools on the Claude and Gemini APIs, RAG pipelines with vector stores.

Currently going deeper on Kubernetes, GCP security posture, and cost optimisation at scale.
